## 版本 A：AI 辅助实现

**项目经历**

**电商智能客服系统 MewHelp — 确定性 Workflow 加 Agent 混合架构的电商售后客服**

技术栈：Python、LangChain、LangGraph、RAG、Milvus、MCP、Langfuse、MySQL

项目介绍：面向电商售后场景的智能客服系统，以确定性 Workflow 加 Agent 混合架构为核心，覆盖 RAG 混合检索问答、九类意图分流、可观测与数据飞轮，以及旁路的主题分类微调。

个人职责：

* 独立负责整体架构设计与全部核心技术决策，借助 Claude Code 完成各模块的编码与调试

* 设计对话主链路：用确定性 Workflow 编排意图分流、混合检索、生成前的证据校验与 Agent 应答

* 负责数据飞轮与配套的主题分类微调，让知识库和问题归类能力随线上数据持续迭代

* 搭建评估体系：RAG 检索评估、意图评估、置信度阈值校准，用评估数据驱动 prompt 与检索策略优化

技术亮点：

* **混合检索**：基于 BGE-M3 语义向量检索，结合 BM25 关键词召回，并通过 RRF 名次融合与 BGE-Reranker 精排，在自建 300 题五桶评估集的 240 道可作答题上把 **Recall@5 提升至 98%、MRR 提升至 89.4%**，答案覆盖度 97%，人工逐条核过的幻觉率 **0.7%**

* **幻觉治理**：基于四信号加权的置信度打分，Agent 回答之前判断证据是否足够，不够就直接转人工、避免答错引发售后纠纷，实测**误放率 0%、误拦率 15%**

* **Workflow 加 Agent 混合架构**：用 LangGraph 编排**九类意图到五个出口**的分流状态机，检索、取订单、查政策等必经步骤由 Workflow 调度，Agent 仅负责证据齐备后的判断与应答，从架构上排除模型跳过必经步骤导致的错误承诺

* **分层上下文**：设计三层上下文管理，结合异步分段摘要与工具结果裁剪，长对话关键信息保留率提升 50%

* **数据飞轮**：设计三入口数据飞轮闭环，把线上答不上的问题沉淀、人工审核后写回知识库，知识缺口补齐，提升系统的**完备性**

* **主题分类微调**：基于 RoBERTa 预训练模型，结合 **17 类多标签**体系与训练数据治理，并通过阈值扫描定标与 ONNX 导出轻量部署，把 161 条测试集上的 **micro-F1 提升至 96.4%**，给飞轮提供知识缺口的主题分布
