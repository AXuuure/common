# 经历蒸馏 · 协议 v0.1

> 目的：不是读专家的结论，是放进专家当年的处境里重走一遍，获得与专家同构的决策模式。
> 与 `软标签材料库/`（本目录子目录）的分工：**材料库 = off-policy 语料**（读专家说了什么）；**本目录其余部分 = on-policy 训练**（在专家的轨迹上做决策、接受纠正）。

## 为什么这是蒸馏的第三形态

| 学习方式 | 对应 ML 概念 | 学到了什么 |
|----------|-------------|-----------|
| 读博客/教程，记结论 | 行为克隆（读 demo） | 事实，换场景就废 |
| 收集软标签材料，挖决策痕迹 | off-policy distillation | 专家的判断分布 |
| **在专家的历史决策点上先自己决策，再对照，再迁移** | **on-policy distillation / DAgger** | **自己的决策模式与专家的差距** |

关键差异：前两种的纠正来自外部材料；第三种学习者产生自己的轨迹（trajectory），在**自己会真实遇到的决策类型**上接受纠正，修正的是自己的策略，不是自己的笔记。

## 四要件（缺一不可）

1. **信息集复刻**——只给当事人当时看得到的信息。AI 的第一职责是**过滤后见之明**：把"2002 年的人不可能知道 microservices 这个词"这类约束显式列出来。
2. **先决策后对照**——必须先写下自己的决策**和推理链**（人类版 CoT），再看专家怎么做的。顺序反了就是读书笔记，不是重走。
3. **机制归因**——差距必须归到"机制缺失"，不能归到"我不知道那个事实"。专家不是知道更多，是有你没注意到的机制设计。
4. **等价迁移**——每一步都要落到自己当前处境的对应决策点。不迁移 = 过家家。

## 重走卡字段规范

```
决策点：谁 / 哪年 / 做了什么决策
├─ 原始信源（含可信度标注：[官方原文]/[转述-未验证]/[学术论文]）
├─ 当时的信息集（只有这些，AI 负责过滤后见之明）
├─ 第一问：开放式情境题（先写，禁查资料）——**禁给 A/B 选项**，选项只能出现在对照段之后
├─ ┄┄ STOP 线：跑到此合卡落笔。下面三段在此之前不许看，制卡时也不许喂给 AI ┄┄
├─ 对照：专家的实际决策
├─ 机制归因：你的方案缺什么机制（不是缺什么知识）
├─ 迁移题：你当前处境的等价决策点是什么
└─ 偏差记录：这次暴露了你的哪类系统性偏差
```

## 跑法规则

**选项禁令（v0.2）**：链路图里"选 A vs 选 B"是**制作人工作台**写法（用来切节点、标重灾区），不是给学习者的内容。出节点卡时必须把岔路改写成开放式情境题，选项挪到对照段之后。违反这条，"先决策后对照"自动失效——二选一的命中率跟决策能力无关。

**单人跑**：读完信息集 → 合上卡片写决策（必须落笔，不许心里想）→ 对照 → 归因 → 迁移 → 记偏差。

**与 AI 跑**（推荐，v0.2 拆成两阶段）：

- **阶段一 · AI 只做信息提供者**：输出"当时的信息集 + 后见之明过滤清单"，并额外列出**它自己知道、但当事人当时不可能知道的 5 件事**，逐条自检这些信息有没有从措辞、顺序、强调或**选项设置**里漏进信息集。此阶段 AI 不得读取或复述对照段。
  **这条不靠自觉**：靠"答案段没进上下文"。制卡时把「信息集」和「对照/归因/迁移」分成两个文件或至少两段，跑之前只喂前者。AI 知道结局是结构性事实，任何"AI 不许透露"的规则都不如"AI 手里没有"可靠。
- **阶段二 · 用户答案落笔之后**：AI 揭示专家决策 + 重建专家思维链，然后**只做归因提问，不做知识讲授**（教练只在揭示阶段说话）。学习者选了非专家岔路时，后果按"岔路结果来源规则"推导并标 [推断]。

## 轻量版：文档反向重建三问（不等卡片，读文档时随手用）

读任何架构文档/设计文档，看到"我们用了 X"时，强制三问：

1. **这个决策在否定什么？**（负向推理：文档文体是"我们有什么"，但关键决策的真实形态多是"我们拒绝什么"。Pi 默认 4 工具，真正的决策是"拒绝功能膨胀"，不是"选择了这 4 个"）
2. **当时的约束是什么？**（什么规模、什么团队、什么遗留系统、什么资金约束）
3. **换我的约束，这个决策反转吗？**（反转了 → 文档结论对你是负样本，照样有信息量）

三问答不上来的文档，就是"看起来莫名其妙"的那类——不是文档差，是它把决策链路压缩掉了，而你在替它补全。答不上来正是需要链路模拟的信号。

## AI 在链路模拟中的角色（创骑定，2026-10-15）

链路模拟不可能 100% 还原——这是现实条件受限，接受。AI 的职责是协助模拟环境条件链路和思维链路，让学习者获得"那种条件下的思路"：

- **检索**：挖一手材料（博客原文、GitHub 历史、访谈），重建当事人可见的信息集
- **推导**：从材料推导决策模型，逻辑链写进卡里，可被质疑
- **知识补全**：材料缺失处用模型知识推论，**必须标 [知识补全-待验证]**

**标注体系在模拟链路里同样有效，且新增第四档**：

| 标注 | 含义 |
|------|------|
| [实测] | 一手原文可抄 |
| [推断] | 从材料推导，逻辑链在卡内 |
| [知识补全-待验证] | 材料缺失，AI 凭知识补的，引用前必须回原文核对 |
| [挖不到] | 禁止引用 |
| [素材不可判] | 当事人**为什么**这么选，材料给不出判定 → 可跑不可归因，不许进偏差档案 |

底线：目标是"学到那种条件下的思路"，不是复现历史真实。允许不完美，**不允许把推论伪装成事实**。

## 元规则：产出不是知识，是偏差档案

单张卡的价值有限。跑 10 张以上后，回看所有"偏差记录"字段，聚类自己反复缺失的机制——那才是蒸馏出来的**关于自己的暗知识**。材料库蒸馏专家，偏差档案蒸馏自己。

**准入三条（v0.2）**：① [素材不可判] 的分叉点不进聚类；② 建立在 [转述-未验证] / [知识补全-待验证] 素材上的归因，必须写明"归因对象是那段文本，不是那个人"；③ 单条链路出现的只算"这局没打好"，在 ≥2 条不相关链路重复出现才算偏差。
**验证集（v0.2）**：每 4–5 条链路留 1 条 held-out——只挑素材、绝不提前研究，隔 ≥2 周盲跑前 3 个节点。盲跑选对率上升才说明蒸出来的是策略而不是事实；这是 L3 唯一"学会了没有"的判据。
