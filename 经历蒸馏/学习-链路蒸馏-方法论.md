> 建立：2026-10-15，基于创骑与小圆的多轮讨论。
> 定位：一套"向专家学习"的完整流程。可复用于任何技术领域，可面试引用。
> 状态：v0.2，随实践迭代。
> **v0.2 修订（2026-10-16）**：新增第五档标注 `[素材不可判]`；铁律从两条扩到三条（第一问禁选项 / 岔路结果来源规则）；机制归因加可迁移性判据；偏差档案加准入规则；新增 held-out 链路当验证集。起因是拿卡 01 和 Zechner 链路图回跑了一遍流程，暴露出四个会让 L3 空转的结构问题。

## 0. 一句话定义

**软标签材料库蒸馏专家的判断分布，经历蒸馏蒸馏自己的决策链路**——前者建语料，后者建偏差档案。

## 1. 起源：从模型蒸馏到人类学习

模型蒸馏（Knowledge Distillation）：大模型当 teacher，输出的不是 one-hot 硬标签而是**带温度软化的完整概率分布**——"70% 猫、20% 老虎、10% 豹"里那 30% 的类间关系，就是暗知识。

类比到人类学习：专家的博客/教程/文档给出的是已经坍缩的结论（hard label），而真正值钱的决策痕迹（淘汰的备选、当时的约束、妥协的过程）几乎从不外泄。

**类比断点（方法论的地基）**：

| | 模型蒸馏 | 人类学习 |
|---|----------|----------|
| soft label 获取成本 | 免费副产品（一次前向传播） | 专家一生决策痕迹里**最不情愿外泄**的部分 |
| 学习者拿到的 | 完整分布 | 一页结论（one-hot） |
| 信息丢失位置 | 几乎不丢 | 在写下博客之前就丢了 |

推论：**"读专家结论"约等于行为克隆，换个场景就废；必须恢复被压缩的链路。**

## 2. 三个结构性坑（不应对策就会虚耗）

1. **幸存者偏差**：只有活着的组织写博客。语料分布 ≠ 真实世界分布，teacher 本身就是 biased 的。
2. **公关美化**：大厂博客是招聘漏斗的一环，天然不写方法的代价。学到方法，学不到成本。
3. **规模错配**：Google 的实践以千名工程师为前提，10 人团队照搬，流程开销比错误本身还贵。同一个答案，语境（temperature）不同，分布不可迁移。

## 3. 文档为什么会"莫名其妙"（结构性丢失）

读架构文档觉得莫名其妙，不是文档差，是三重**结构性**丢失：

1. **负向推理不可见**：文档文体是"我们有什么"，但关键决策的真实形态多是"我们拒绝什么"。（Pi 默认 4 工具，真正的决策是"拒绝功能膨胀"，不是"选择了这 4 个"。）
2. **约束温度丢失**：文档不写"本结论仅在 X 约束下成立"——写了显得不自信，也没法卖。
3. **作者自己都没显式化**：决策模型散落在 issue 和口头争论里，README 是事后补的压缩残骸。

推论：**链路模拟不是学习技巧，是恢复被压缩信息的唯一手段。**

## 4. 三层结构（总图）

```
学习-链路蒸馏
│
├── L1 软标签材料库（off-policy）
│   目的：建"专家判断分布"的语料
│   动作：按 T1/T2/T3 信源梯队挖材料 → 四层卡拆解
│   产出：可扛面试追问的 T1 引用锚点
│
├── L2 文档反向重建三问（轻量版，读文档随手用）
│   动作：看到任何"我们用了 X"强制三问
│   产出：识别"此处需要链路模拟"的信号
│
└── L3 经历蒸馏（on-policy）
    目的：建"自己决策模式"的偏差档案
    动作：链路切分 → 信息集复刻 → 先决策后对照 → 机制归因 → 等价迁移
    产出：偏差指纹 / 分叉树
```

## 5. L1 软标签材料库（off-policy）

**四层卡字段**：

| 层 | 内容 | 回答的问题 |
|----|------|-----------|
| 结论层 | 他们公开说了什么 | 可引用的一句话锚点是什么 |
| 软标签层 | 决策痕迹/淘汰的备选/当时的约束 | 暗知识在哪 |
| 降温层 | 在我的约束下成不成立 | 换我还成立吗 |
| 缺口层 | 这份材料缺什么/哪里被过滤 | 哪不能引、哪要补 |

**核心认知**：同一篇材料，结论层人人看得见，软标签层才需要挖——而它通常不在正文里，在 postmortem、ADR（"为什么不用 X"）、rejected PR、issue 争论里。挖不到就留空标缺口，**不许拿记忆冒充**。

## 6. L2 文档反向重建三问

看到任何架构/设计文档里的"我们用了 X"，强制三问：

1. **这个决策在否定什么？**（负向推理）
2. **当时的约束是什么？**（规模/团队/遗留系统/资金）
3. **换我的约束，这个决策反转吗？**（反转了 → 文档结论对你是负样本，照样有信息量）

三问答不上来 = 遇到了被压缩的文档 = 需要 L3 的信号。

## 7. L3 经历蒸馏（on-policy）

### 术语

- **链路**：一个人的一段完整决策序列（5–8 个节点为宜）
- **节点**：序列上的单个岔路——**切"可选决策"，不切"事件"**（"AWS 上线"是事件；"决定把内部基础设施对外卖"才是节点。判据：当事人当时有没有真实岔路、选错有没有代价）

### 四要件（缺一不可）

1. **信息集复刻**：只给当事人当时看得到的信息。AI 的第一职责是**过滤后见之明**（显式列出"当时不可能知道的事"）。
2. **先决策后对照**：必须先写下自己的决策再看专家。顺序反了就是读书笔记。
3. **机制归因**：差距归到"机制缺失"，不归到"我不知道那个事实"。专家不是知道更多，是有你没注意到的机制设计。
   **机制防伪判据（v0.2）**：机制必须写成"缺了它，我在 X 类场景会犯 Y 类错"的**预测句**，并且能在另一条**没跑过的链路**上做出预测。只能在当前链路里自洽的"机制"，是事实穿了马甲，不进偏差档案。理由：机制归因这一侧的编故事风险和材料那一侧的公关美化是同构的——前者是你在给自己造 soft label。
4. **等价迁移**：每步落到自己当前处境的对应决策点。不迁移 = 过家家。
   **迁移题有效性判据（v0.2）**：迁移题必须在"不知道刚归因的那条机制"的前提下答不出来。如果不知道机制、只靠常识也能答得漂亮，这道题考的是常识不是机制，换掉。

### 三层模拟模型（创骑提出，2026-10-16）

人类决策与 agent 推理同构：**环境 ↔ 上下文，思维链 ↔ CoT，最终决策 ↔ 输出**。所以链路模拟必须三层都模拟，只模拟结论是残缺的：

| 层 | 人类侧 | Agent 侧 | 模拟手段 | 现状 |
|----|--------|----------|----------|------|
| 上下文层 | 环境/约束/可见信息 | context | 信息集复刻 + 后见之明过滤清单 | ✅ 已实现 |
| 思维链层 | 推理路径/排除的逻辑 | CoT | 重建专家的推理链 + 学习者先写自己的推理链 | ⬜ 本版新增 |
| 输出层 | 最终决策 | output | 对照专家的实际决策 | ✅ 已实现 |

**学习者侧同步三层**：第一问不只写"我选什么"，必须写"我的推理链"（人类版 CoT）。对照时三层分别归因——差在信息集？差在推理链？还是只差结论？归因到不同层，纠正动作完全不同。

**重建专家思维链的素材来源**：博客长文里的自述（"我当时想的是……"）、访谈里的反问、RFC/issue 里的论证过程、事后复盘的"我们最初以为……后来发现……"。这些材料比结论稀有得多，但正是它们让模拟成为可能。

**失败模式同构（对学 agent 是双重收益）**：

- 上下文污染 ↔ **后见之明污染**：拿今天的信息替当时的人决策 = 给 agent 喂未来数据，必然过拟合出一个"事后诸葛亮"式的错误策略
- 思维链断裂 ↔ 只会复述结论不会推理 = agent 跳过 CoT 直接输出，换输入就崩
- student collapse ↔ 学形式不学机制（张口专家语录，自己场景全对不上）

**反向收益**：给人做"信息集复刻"本质上就是**上下文工程练习**——什么信息该进上下文、什么是噪声、什么导致决策变形。跑多了对上下文管理的体感直接迁移到 RAG / 评估平台 / ChorusTavern 的设计。

### 铁律（v0.2 起四条）

- **状态继承**：第 N 个节点的起点 = 前 N-1 个节点的实际后果。选偏了**不许回头改**——路径依赖的体感只能这么来。（例：Zechner 公开拒绝 MCP 抬高了他后来反转的信誉成本，不跑前节点感受不到这个难度。）
- **第一问禁选项**（v0.2，最重要的一条）：给学习者的节点卡，第一问必须是开放式情境题，不许出现"A vs B"。链路图里的岔路是从专家历史里挑出来的——学习者一看到选项，任务就从"在开放情境里做心理模拟"退化成"在两个已知答案里蒙一个"，命中率跟真实决策能力无关。**选项只允许出现在对照段之后**，作为"当事人当时怎么框定这个问题"的复盘材料。
- **岔路结果来源规则**（v0.2）：只有**专家实际走过的那条路**的后果可以有 [实测] 信源。学习者选了别的岔路时，后果必须由 AI 从当时可见的约束推导、标 [推断]，**禁止把专家路径的历史结果借来判定学习者那条路**。借了就等于用后见之明惩罚没走过的路，还会造出根本不可能做对的节点。
- **链路结束必做路径复盘**：画"我的链路 vs 专家的链路"分叉树，分叉点按类型聚类（信息不足/机制缺失/风险偏好不同）= 这条链路蒸出的**偏差指纹**（聚类前置准入检查见 §9）。

## 8. AI 协作契约（链路模拟的边界）

链路模拟不可能 100% 还原——现实条件受限，接受。AI 的职责是协助模拟环境条件链路和思维链路：

- **检索**：挖一手材料重建当事人可见的信息集
- **推导**：从材料推导决策模型，逻辑链可被质疑
- **知识补全**：材料缺失处凭知识推论，必须标注

**标注体系（四档）**：

| 标注 | 含义 | 可用性 |
|------|------|--------|
| [实测] | 一手原文可抄 | 可直接引用 |
| [推断] | 从材料推导，逻辑链在卡内 | 可说"我的判断是" |
| [知识补全-待验证] | AI 凭知识补的 | 引用前必须回原文核对 |
| [挖不到] | 信源不可达 | 禁止引用 |
| [素材不可判] | 当事人**为什么**这么选，材料给不出判定 | 可跑不可归因：能拿来练决策，**不许写进偏差档案** |

**底线：允许不完美，不允许把推论伪装成事实。** 目标是"学到那种条件下的思路"，不是复现历史真实。

## 9. 元规则

- **材料库蒸馏专家，链路蒸馏自己。**
- 单张卡/单个节点价值有限；跑 10+ 节点后回看偏差记录做跨链路聚类——那才是蒸出来的**关于自己的暗知识**。
- 失败链路比成功链路更值得蒸（Spotify 的 squad 兴衰 > Spotify 的成功故事）。
- **偏差档案准入规则**（v0.2）：三条排除项，否则会把信源缺陷蒸成自己的系统性偏差——
  1. 标 [素材不可判] 的分叉点不进聚类；
  2. 建立在 [转述-未验证] / [知识补全-待验证] 素材上的归因，进档案必须写明"**归因对象是那段文本，不是那个人**"（卡 01 就是此例：mandate 只经 Yegge 转述，所以"你没做到三条"是对一个 2011 年帖子的服从度测试，不是对 Bezos 决策模式的对照）；
  3. 只有一条机制在 ≥2 条不相关链路上重复出现，才算"偏差"，单链路出现的算"这一局没打好"。
- **held-out 链路 = L3 的验证集**（v0.2）：L3 目前没有任何"学会了没有"的判据，这是它和读书笔记的唯一分水岭。做法：每攒 4–5 条链路，留 1 条只挑素材、自己绝不提前研究（不读链路图、不读节点表），隔 ≥2 周后盲跑前 3 个节点。**盲跑选对率上升 = 蒸出的是策略；只在本链路里答对 = 记住的是事实。**这条同时是"机制防伪判据"的实测场——你写的机制能不能在新链路上做出预测，跑一次就知道。

## 10. 信源规范（承接创骑既有三梯队）

- **T1 国际大厂**：官方工程博客/白皮书/文档/高管署名。找不到就明说找不到。
- **T2 国内大厂**：官方技术博客/出版物/青训营教材。
- **T3 大牛分享**：领域公认源头人物的著作与博客。
- **反向清单**：CSDN/51CTO/简书/知乎/人人都是产品经理的"大厂总结"——不可当 citation，最多交叉印证。
- 额外要求：决策点素材必须标信源可信度（[官方原文]/[转述-未验证]/[学术论文]），[转述-未验证] 引用时带"据广泛转述"字样。
