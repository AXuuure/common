# 经历蒸馏 · 计划 v0.1（草案）

> 状态：v0.1 初稿，待创骑 review 后定 v1.0。本文只定方向和规则，具体链路逐条展开。
> 建立日期：2026-10-15

## 目标

找到**经历被详细记录、决策心路可挖、有第一人称思想分享**的人物或组织，把他们的关键决策序列切成"链路"，在 AI 的陪跑下逐节点重走：先自己决策，再对照专家，最后迁移到自己的等价处境。

一句话：**软标签材料库蒸馏专家的"判断分布"，经历蒸馏蒸馏自己的"决策链路"**——前者建语料，后者建偏差档案。

## 选材三标准（缺一不选）

| 标准 | 具体要求 | 不满足的样子 |
|------|----------|--------------|
| ① 经历可考 | 有时间线、有事实锚点，多源可交叉 | 只有光环叙事，年份都对不上 |
| ② 决策心路可挖 | 有"为什么选 A 不选 B"的痕迹：博客长文、访谈、复盘、RFC 废弃稿 | 只有结论没有过程，"我们当时就很坚定" |
| ③ 思想可对照 | 本人对决策的第一人称解释，能拿来跟自己的解释对比 | 全是第三方的"他很厉害"式转述 |

**反面清单（一问就穿帮型，禁止入选）**：

- 光环厚但经历不可考：乔布斯——传记汗牛充栋，但决策细节大量是事后重构和神话层
- 只有结论没有痕迹：大厂总监的公众号复盘（自称内部视角，核实不到）
- 思想多、决策少：纯评论者/分析师——讲得都对，但没有可复现的决策序列
- 单人记忆且无多源交叉的"内部故事"：除非明确标注[转述-未验证]，否则不进候选池

## 链路切分方法

**链路** = 一个人的一段完整决策序列；**节点** = 序列上的单个岔路。

1. **切"可选决策"，不切"事件"**。每个节点必须是当事人当时面对的真实岔路（有 A/B 可选，且选错有代价）。"2006 年 AWS 上线"是事件，不是节点；"2003 年决定把内部基础设施对外售卖"才是节点。
2. **一条链路 5–8 个节点**。少于 5 个不成链，多于 8 个跑不动。
3. **每个节点的信息集三件套**：当事人可见的信息 / 当事人当时的约束 / **过滤掉的后见之明清单**（明确写出"当时不可能知道的事"，防止用 2026 年的认知作弊）。

## 模拟规则（链路怎么跑）

- **状态继承**：第 N 个节点的起点 = 前 N-1 个节点的实际后果。如果自己前面选偏了，**带着选偏的后果继续走**，不允许回头改——路径依赖的体感正是这么来的。
- **转折点标记**：专家做过反直觉选择的节点标"重灾区"——这里最可能暴露自己的系统性偏差，值得多跑一遍。
- **单节点流程**：读信息集 → 合卡写决策（必须落笔）→ 对照专家 → 机制归因 → 迁移题 → 记偏差。
- **链路结束必做路径复盘**：画"我的链路 vs 专家的链路"分叉树。分叉点按类型聚类（信息不足？机制缺失？风险偏好不同？）——这就是这一链路蒸出来的偏差指纹。

## 产出结构

```
经历蒸馏/
├── README.md              协议（四要件 + 跑法 + 元规则）
├── 计划.md                本文件
├── 软标签材料库/           L1：off-policy 语料（四层卡 + 三/四档标注）
│   ├── README.md
│   ├── T1-<信源>.md       样板卡
│   └── ...
├── 链路-<名称>/
│   ├── 链路图.md          制作人工作台：节点序列 + 状态继承（含"vs"岔路，禁止外泄到卡）
│   ├── 节点卡-01-xxx-题目.md   只含：信源 / 信息集 / 后见之明过滤 / 第一问（开放式，禁选项）
│   ├── 节点卡-01-xxx-答案.md   对照 / 专家思维链 / 机制归因 / 迁移题 —— 落笔前不打开、不喂 AI
│   └── 路径复盘.md        跑完后填：分叉树 + 偏差指纹
└── 偏差档案.md            跨链路累积，跑 10+ 节点后启用聚类（准入三条见方法论 §9）
```

## 节奏

- 一批 = 1 条链路；节点逐张过，不一次性全出——保持"先决策"的张力，也给你留消化的时间
- 每条链路跑完做一次路径复盘，累积到 10+ 节点后开 `偏差档案.md` 做跨链路聚类
