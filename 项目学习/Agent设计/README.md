## 五篇怎么串起来读

```
第1课 定义层   意图从哪来：对象+动作，说明卡（同时供模型/标注/评测使用）
                 ↓ 有了封闭类别集合，才能量化
第2课 单类指标  一个类别的 TP/FP/FN/TN → P / R / Fβ
                 ↓ 十个类别怎么合成一个系统分数
第3课 多类指标  混淆矩阵 + Micro（按次）/ Macro（按类）+ β 按业务成本定
                 ↓ 分类器只是 Agent 的一个零件，整体架构怎么定
第4课 架构分层  执行控制 / 参与拓扑 / 运行系统 / 实现载体，先分层再选型
                 ↓ 架构跑起来之后，怎么证明它真的有用
第5课 任务评测  需求维度聚合 + 版本管理 + 三方分工 + 五个核心指标 + 归因闭环
```

第 1–3 课是一条线（分类器），第 4–5 课是另一条线（Agent 系统与评测）。两线的接缝在第 4 课末尾那句话：**评测不能只看最后答案，还要能定位是单个 Agent、路由、handoff 还是汇总出了问题**——第 5 课用 Trace / Observation 层级和 `req_id` 聚合来兑现它。
